# SG Reno Solution — Premium Website

This is a free, static website for GitHub Pages. No subscription or paid hosting required for a public repository.

## Update your existing GitHub website
1. Open https://github.com/Nirobweb1/sg-reno-solution
2. Select **Add file → Upload files**.
3. Extract the ZIP first. Upload the four files `index.html`, `style.css`, `script.js`, `favicon.svg` to the repository ROOT (not into `assets/`).
4. GitHub may ask to replace existing files. Confirm the updates and select **Commit changes** to `main`.
5. Wait for Pages deployment and refresh https://nirobweb1.github.io/sg-reno-solution/
